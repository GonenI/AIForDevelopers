# Shooter Game

A simple target shooting game where you need to click on a moving red target to score points.

## Features

- Moving red target that bounces around the screen
- Score tracking
- Crosshair cursor for better aiming
- Target speed increases slightly with each hit
- Simple and responsive controls

## How to Play

1. Install the required dependencies:
   ```
   pip install pygame
   ```

2. Run the game:
   ```
   python shooter_game.py
   ```

3. Click on the red target to shoot it and earn points
4. The target will respawn in a new location after each hit
5. Target speed increases slightly as your score increases

## Controls

- **Mouse Movement**: Aim the crosshair
- **Left Click**: Shoot at the target
- **Close Window**: Exit the game

## Game Mechanics

- The target moves in a random direction and bounces off the screen edges
- Each successful hit increases your score by 1
- The target gets slightly faster with each hit to increase difficulty
- Target radius is 30 pixels for reasonable difficulty

Enjoy the game!
